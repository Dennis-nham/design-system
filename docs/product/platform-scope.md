# Phạm vi nền tảng

## Phạm vi dự kiến cho v1

- Design tokens (CSS variables và định dạng nguồn có thể build).
- UI kit web gồm controls và patterns phổ biến, API được tài liệu hóa.
- Tài liệu component với ví dụ sử dụng, variants, trạng thái và giới hạn.
- Package npm có types, entry points ổn định và hướng dẫn cài đặt.
- Ứng dụng docs/demo để tra cứu và kiểm thử trực quan.
- CI cho lint, typecheck, unit/component tests, build và kiểm tra package.

## Ngoài phạm vi v1

Marketplace, cloud hosting, AI UI builder, backend service, ứng dụng mobile native và bộ component cho nhiều framework. Chỉ mở rộng sau khi có maintainer, nhu cầu xác thực và kế hoạch bảo trì.

## Quyết định cần chốt

Framework, browser support, cách quản lý theme, CSS strategy, định dạng package, license, versioning và chính sách hỗ trợ. Không tạo cam kết tương thích trước khi các quyết định này có owner và ADR.
