# Danh mục đặc tả UI

Các tài liệu này mô tả hợp đồng thiết kế mong muốn, không khẳng định component đã được triển khai.

Ngôn ngữ thị giác tham khảo iOS 16 và cách điều chỉnh cho web được mô tả trong [hướng dẫn iOS 16](../ios16-reference.md).

| Đặc tả | Atomic level | Phạm vi chính |
| --- | --- | --- |
| [Button](button.md) | Atom | Hành động, trạng thái và kích thước |
| [Input và text fields](input.md) | Atom/molecule | Label, help, error, validation |
| [Avatar và profile](avatar-profile.md) | Atom/molecule | Hình đại diện và nhận diện người dùng |
| [Calendar, date và time](calendar-date-time.md) | Molecule/organism | Chọn ngày giờ, locale, timezone |
| [Menubar và navbar](menubar-navbar.md) | Organism | Điều hướng và tương tác bàn phím |
| [Tooltip và toast](tooltip-toast.md) | Molecule/organism | Nội dung trợ giúp và thông báo |
| [Emoji và controls](emoji-controls.md) | Atom/molecule | Emoji picker và control cơ bản |
| [Cover và thumbnail](cover-thumbnail.md) | Atom/molecule | Media preview và trạng thái tải |

Mỗi tài liệu phải được cập nhật cùng API triển khai và ví dụ tương ứng.
